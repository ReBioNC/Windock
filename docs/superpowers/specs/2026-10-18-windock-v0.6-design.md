# Windock v0.6 — New features design

| | |
|---|---|
| Date | 2026-10-18 |
| Status | Approved by the user (chat 2026-10-18) |
| Principle | Every feature has an option in Settings and applies immediately. Idle RAM stays about 50 MB; rarely used parts are created when opened and dropped afterwards. |

## Features and their options

### 1. Status area (right end of the dock)
A fixed segment on the right, after the Recycle Bin and a separator. Its icons do not grow with magnification and are drawn with the **Segoe MDL2 Assets** font (built into Windows 10).

| Button | Shows | Click | Extra |
|---|---|---|---|
| ^ Tray | chevron | a Windock popup with every tray icon (visible + hidden); left/right/double clicks are forwarded to the real icon through Explorer's tray toolbar, so the taskbar stays hidden (v0.6.1, replaced method A) | — |
| Wi-Fi | signal / cable / disconnected | `ms-availablenetworks:` | updated via `NetworkChange` |
| Volume | speaker (level/mute) | Windock slider popup | scroll ±2 %, middle-click = mute; Core Audio + callback |
| Battery | battery icon (+ %) | `ms-settings:batterysaver` | hover: time left/state; hidden automatically on PCs without a battery |
| Language | "EN", "ID", … | Win+Space (switch input language) | read from the active window's keyboard layout |
| Clock | time (+ date) | calendar popup | updated every minute (or every second when seconds show) |
| Notifications | notification icon | `ms-actioncenter:` | — |

**Options** (*Status area* page): area on/off; each button on/off; 24/12-hour clock; show date; show seconds; show battery percentage.

### 2. Icons asking for attention
A flashing window (`HSHELL_FLASH` via `RegisterShellHookWindow`) marks its icon until that window becomes active. **Options:** style *Bounce / Red dot / Off* (default Bounce); repeat *Once / Until opened* (default Until opened).

### 3. Smart Recycle Bin
Drag files onto the Recycle Bin icon → they move to the Recycle Bin (`SHFileOperation` + `FOF_ALLOWUNDO`, restorable). The icon follows full/empty. Right-click: *Open*, *Empty Recycle Bin* (Windows' confirmation). The drag effect reported to Explorer is **not** Move, so Explorer does not delete the source as well. **Options:** show the Recycle Bin; confirm before trashing (default on).

### 5. Hide apps
Right-click a running app that is not pinned → *Don't show in dock*. **Options:** a *Hidden* list in Dock items with a *Show again* button.

### 6. Theme
Plate background color (presets + hex), corner radius 0–30 (default 16), border on/off, indicator dot color, accent color (menus, previews, Settings), *follow the wallpaper color* (the wallpaper's average color, darkened; computed at start and when the wallpaper changes). New **Theme** page.

### 7. Bounce while opening + start with Windows
Bounce: the icon rises 0.5× its size over 300 ms, falls over 300 ms, rests 100 ms; until the first window appears or 10 seconds (DESIGN §4). Startup: the `Windock` value in `HKCU\…\Run`. **Options:** both on/off in Behavior (bounce default on, startup default off).

### 9. Launcher (Alt+Space)
A search window at the top center of the screen; type → result list (icon + name) → Enter/click opens, Esc closes. Index: Start Menu shortcuts (user + common) and Store apps (`shell:AppsFolder`); optionally files on the Desktop/Documents. The index is built when the launcher opens and dropped when it closes. Ranking: prefix > word start > contains > subsequence. **Options:** on/off, shortcut (1 modifier + Space allowed), number of results 5–12 (default 8), also search files (default off).

## Shared technical changes
- `DockSettings` gets new `init` properties (`Theme`, `Status`, `Launcher`, `Trash`, `HiddenApps`) with defaults; `BehaviorSettings` gets `Attention`, `AttentionRepeat`. All are read tolerantly per field and tested.
- `HotkeyGesture` supports `Space` and a minimum number of modifiers per use (emergency ≥ 2, launcher ≥ 1). `HotkeyService` supports several hotkeys.
- `DockLayoutEngine`: an item kind `Fixed` (does not grow) for the status area.
- New registry use: only `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (startup). `uninstall.ps1` removes it.
