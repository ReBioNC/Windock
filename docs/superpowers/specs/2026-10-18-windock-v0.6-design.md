## Fitur dan opsinya

### 1. Area status (ujung kanan dock)
Segmen tetap di kanan, setelah Recycle Bin dan pemisah. Ikon tidak ikut membesar (magnification) dan digambar dengan font **Segoe MDL2 Assets** (bawaan Windows 10).

| Tombol | Tampilan | Klik | Ekstra |
|---|---|---|---|
| ^ Tray | panah | popup Windock berisi semua ikon tray (yang tampil + tersembunyi); klik kiri/kanan/dobel diteruskan ke ikon aslinya lewat toolbar tray Explorer, taskbar tetap tersembunyi (v0.6.1, menggantikan cara A) | — |
| WiFi | sinyal / kabel / putus | `ms-availablenetworks:` | update via `NetworkChange` |
| Volume | speaker (level/mute) | popup slider Windock | scroll ±2 %, klik tengah = mute; Core Audio + callback |
| Baterai | ikon baterai (+ %) | `ms-settings:batterysaver` | hover: sisa waktu/status; disembunyikan otomatis di PC tanpa baterai |
| Bahasa | "EN", "ID", … | Win+Space (ganti bahasa input) | dibaca dari layout keyboard jendela aktif |
| Jam | jam (+ tanggal) | popup kalender | update per menit (atau per detik bila detik tampil) |
| Notifikasi | ikon notifikasi | `ms-actioncenter:` | — |

**Opsi** (halaman *Area status*): area hidup/mati; tiap tombol hidup/mati; jam 24/12; tampilkan tanggal; tampilkan detik; tampilkan persen baterai.

### 2. Ikon minta perhatian
Jendela yang berkedip (`HSHELL_FLASH` lewat `RegisterShellHookWindow`) menandai ikonnya sampai jendela itu aktif. **Opsi:** gaya *Memantul / Titik merah / Mati* (default Memantul); ulang *Sekali / Sampai dibuka* (default Sampai dibuka).

### 3. Recycle Bin pintar
Seret file ke ikon Recycle Bin → dipindah ke Recycle Bin (`SHFileOperation` + `FOF_ALLOWUNDO`, bisa dipulihkan). Ikon mengikuti penuh/kosong. Klik kanan: *Buka*, *Kosongkan Recycle Bin* (konfirmasi Windows). Efek drag yang dilaporkan ke Explorer **bukan** Move, supaya Explorer tidak ikut menghapus sumber. **Opsi:** tampilkan Recycle Bin; konfirmasi sebelum membuang (default hidup).

### 5. Sembunyikan aplikasi
Klik kanan aplikasi jalan yang tidak di-pin → *Jangan tampilkan di dock*. **Opsi:** daftar *Disembunyikan* di Isi Dock dengan tombol *Tampilkan lagi*.

### 6. Tema
Warna latar plate (preset + hex), kebulatan sudut 0–30 (default 16), garis tepi hidup/mati, warna titik penanda, warna aksen (menu, pratinjau, Pengaturan), *ikuti warna wallpaper* (rata-rata warna wallpaper, digelapkan; dihitung saat start dan saat wallpaper berubah). Halaman baru **Tema**.

### 7. Memantul saat dibuka + jalan saat Windows nyala
Memantul: ikon naik 0,5× ukuran selama 300 ms, turun 300 ms, jeda 100 ms; sampai jendela pertama muncul atau 10 detik (DESIGN §4). Startup: nilai `Windock` di `HKCU\…\Run`. **Opsi:** keduanya hidup/mati di Perilaku (memantul default hidup, startup default mati).

### 9. Launcher (Alt+Space)
Jendela pencarian di tengah atas layar; ketik → daftar hasil (ikon + nama) → Enter/klik membuka, Esc menutup. Indeks: shortcut Start Menu (user + common) dan aplikasi Store (`shell:AppsFolder`); opsional file di Desktop/Documents. Indeks dibuat saat launcher dibuka dan dibuang saat ditutup. Peringkat: awalan > awal kata > mengandung > subsequence. **Opsi:** hidup/mati, shortcut (boleh 1 modifier + Space), jumlah hasil 5–12 (default 8), ikut cari file (default mati).

## Perubahan teknis bersama
- `DockSettings` mendapat properti `init` baru (`Theme`, `Status`, `Launcher`, `Trash`, `HiddenApps`) dengan default; `BehaviorSettings` mendapat `Attention`, `AttentionRepeat`. Semua dibaca toleran per-field dan diuji.
- `HotkeyGesture` mendukung `Space` dan jumlah modifier minimum per pemakaian (darurat ≥ 2, launcher ≥ 1). `HotkeyService` mendukung beberapa hotkey.
- `DockLayoutEngine`: jenis item `Fixed` (tidak ikut membesar) untuk area status.
- Registry baru: hanya `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (startup). `uninstall.ps1` menghapusnya.
