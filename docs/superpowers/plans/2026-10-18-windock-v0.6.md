# Windock v0.6 Implementation Plan

> Run inline (like v0.1). Every task: Core tests first (RED → GREEN), then App code, a manual test on the laptop, commit + push. Progress is tracked with check marks in this file.

**Spec:** [2026-10-18-windock-v0.6-design.md](../specs/2026-10-18-windock-v0.6-design.md)

## Global Constraints
- Every feature has an option in Settings; changes apply immediately.
- Idle RAM about 50 MB; popups and the launcher are created when opened and dropped afterwards; no polling except the clock (per minute or second).
- Core has no WPF/Win32; Win32 only in `src/Windock/Interop`.
- Windock never deletes files permanently; trashing a file = Recycle Bin (`FOF_ALLOWUNDO`).
- UI text in Indonesian at the time (translated to English in v0.9); commits use Conventional Commits + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
