# Windock v0.1 (Fase 0 + Fase 1: Dock Inti) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dock ala macOS yang bisa dipakai harian di Windows 10: pin dan aplikasi jalan, magnification, blur, ruang layar dicadangkan, taskbar disembunyikan dengan pemulihan aman, dan jendela Pengaturan yang langsung diterapkan.

**Architecture:** Logika murni (pengaturan, model dock, tata letak, animasi, keputusan klik, koordinasi taskbar) ada di `Windock.Core` (net8.0, tanpa WPF dan Win32) dan diuji dengan xUnit. Aplikasi WPF `Windock` hanya berisi jendela, renderer, dan wrapper Win32 di `Interop/`, yang mengimplementasikan interface dari Core. Dua spike di awal memvalidasi blur dan penyembunyian taskbar sebelum kode produksi ditulis.

**Tech Stack:** C# 12, .NET 8 (SDK 8.0.400), WPF, Microsoft.Windows.CsWin32, System.Text.Json, xUnit, GitHub Actions.

**Spec:** [docs/PRD.md](../../PRD.md), [docs/DESIGN.md](../../DESIGN.md), [docs/ARCHITECTURE.md](../../ARCHITECTURE.md)

**Di luar plan ini (Fase 2, plan terpisah):** F-07 (pindah antarjendela), F-10 (memantul), F-11 (drag urutkan di dock), S-01 kiri/kanan, S-07 dock auto-hide, S-08, S-09, dan ajakan "Jalankan saat Windows nyala" saat pertama kali dijalankan. T-02 (mode auto-hide taskbar) ikut dikerjakan di plan ini, karena hanya beberapa baris di `TaskbarModeCoordinator`.

## Global Constraints

- Core: `net8.0`. App: `net8.0-windows`. Test: `net8.0`. `<Nullable>enable</Nullable>`, `<LangVersion>12</LangVersion>`, `<TreatWarningsAsErrors>true</TreatWarningsAsErrors>` di semua project.
- `Windock.Core` tidak boleh mereferensi WPF, WinForms, atau Win32. `Windock` boleh mereferensi Core, tidak sebaliknya.
- Panggilan Win32 hanya di `src/Windock/Interop/`.
- `app.manifest`: `requestedExecutionLevel level="asInvoker"`, `dpiAwareness` `PerMonitorV2`, dan `supportedOS` Windows 10.
- Penulisan file hanya di `%AppData%\Windock\`. Registry: tidak ada di v0.1. Setelan taskbar hanya lewat `ABM_SETSTATE`, dan dicatat di `state.json` sebelum diubah.
- Tidak ada injeksi DLL, hook in-process, `TerminateProcess`, atau akses jaringan. Menutup jendela hanya lewat `WM_CLOSE`.
- Dependensi NuGet hanya: `Microsoft.Windows.CsWin32`, `xunit`, `xunit.runner.visualstudio`, `Microsoft.NET.Test.Sdk`.
- Identifier kode dalam bahasa Inggris. Teks UI yang dilihat pengguna dalam bahasa Indonesia, sesuai DESIGN.md.
- Semua ukuran dalam DIP. Nilai default dan konstanta diambil persis dari DESIGN.md §2, §3, §4, dan §6.
- Commit memakai Conventional Commits dan diakhiri `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Push ke `origin main` setelah setiap task selesai.

## Review Focus

1. **Terlalu banyak aplikasi untuk lebar layar:** dock tidak boleh melebihi layar. Ikon mengecil merata supaya plate muat (test di Task 6).
2. **`settings.json` diedit manual dengan satu nilai salah:** hanya field itu yang kembali ke default, sisanya tetap (test di Task 4).
3. **Windock dimatikan paksa saat taskbar disembunyikan:** saat Windock dijalankan berikutnya, taskbar dan setelan auto-hide asli dipulihkan sebelum apa pun (test di Task 8).
4. **Proses yang path exe-nya tidak bisa dibaca** (proses terproteksi atau Administrator): jendelanya tetap tampil dengan identitas dari nama proses (test di Task 7).
5. **Pin ke aplikasi yang sudah di-uninstall, atau pin ganda:** pin tetap tampil tanpa crash, dan pin ganda digabung menjadi satu ikon (test di Task 7).

  - `readonly record struct ItemLayout(string Key, LayoutItemKind Kind, RectD Bounds, double SlotProgress, double IndicatorCenterX, double IndicatorCenterY)`
  - `sealed record LayoutResult(RectD Plate, RectD ActiveZone, IReadOnlyList<ItemLayout> Items, double EffectiveIconSize)`
  - `static class DockLayoutEngine { LayoutResult Compute(LayoutInput input); }`

Algoritma (koordinat relatif ke `DockWindow`, dengan origin di kiri atas):

```
1. baseIcon = IconSize; perbandingan = MagnifiedSize / IconSize
   lebarDasar = 2*PlatePaddingH + Σ(Icon: baseIcon+IconSpacing, Separator: SeparatorSlotWidth) × SlotProgress
   jika lebarDasar > ScreenWidth − 2*ScreenMargin:
       baseIcon = (ScreenWidth − 2*ScreenMargin − 2*PlatePaddingH − ΣSep×p − ΣIcon p×IconSpacing) / ΣIcon p
   magnified = baseIcon × perbandingan; R = ReachFactor × baseIcon
2. Pusat dasar tiap item dihitung dari tata letak tanpa magnification, berpusat di ScreenWidth/2
3. Untuk Icon: d = CursorX − pusatDasar (jika CursorX null atau magnification mati, skala = 1)
   t = min(|d|/R, 1); s = 1 + (magnified/baseIcon − 1) × cos²(t·π/2)
   s = 1 + (s − 1) × MagnifyProgress; ukuran = baseIcon × s
   lebarSlot = (ukuran + IconSpacing) × SlotProgress
4. Plate: lebar = 2*PlatePaddingH + Σ lebarSlot; X = (ScreenWidth − lebar)/2
   tinggi = PlateHeight(baseIcon); Y = WindowHeight − EdgeGap − tinggi
5. Ikon ditambatkan di bawah: bottom = Plate.Bottom − PlatePaddingV − IndicatorSpace; berada di tengah slot
   Indicator: CenterX = Bounds.CenterX; CenterY = Bounds.Bottom + IndicatorOffset + IndicatorDiameter/2
   Separator: Bounds lebar 1, tinggi 0.6×baseIcon, CenterY sama dengan pusat ikon dasar, di tengah slot
6. ActiveZone: jika CursorX != null atau MagnifyProgress > 0, maka X = Plate.X, lebar = Plate.Width,
   Y = min(Plate.Y, min Bounds.Y ikon), bottom = WindowHeight. Jika tidak, Plate dari Plate.Y sampai WindowHeight.
```
