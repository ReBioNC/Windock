# Windock v0.1 — Manual test checklist

Source: [ARCHITECTURE.md §11](../ARCHITECTURE.md#11-testing-strategy). Test machine: Windows 10 22H2 (19045), 1920×1080, 100% scaling.
The "Claude" column was filled from automated tests (PowerShell probes + UI Automation) during development, 2026-10-16. The "User" column is for the final test.

## If something goes wrong

1. Press `Ctrl+Alt+Shift+W`.
2. Send the contents of `%AppData%\Windock\logs\windock-<date>.log`.
3. The manual taskbar recovery steps are in the [README](../../README.md#if-the-windows-taskbar-does-not-come-back).
